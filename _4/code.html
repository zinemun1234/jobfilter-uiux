조직 소개 (HyperCLOVA X 서빙 플랫폼)

인프라 코어 엔지니어링

네이버클라우드 HyperCLOVA X 서빙 플랫폼 팀은 대한민국 최고의 초대규모 생성형 인공지능 모델을 수백만 B2B/B2C 사용자가 단 1밀리초의 지연 없이 이용할 수 있도록 지원하는 초저지연 분산 백엔드 아키텍처를 설계하고 운영합니다.

담당 업무 (Responsibilities)

1

초대규모 AI 언어모델 HyperCLOVA X의 API 서빙 백엔드 인프라 아키텍처 개발

LLM 모델 토큰 스트리밍 응답 처리를 위한 고가용성 gRPC / RESTful API 게이트웨이 파이프라인 개발 및 세션 라우팅 엔진을 구현합니다.

2

대용량 분산 트래픽 처리를 위한 마이크로서비스(MSA) 및 비동기 파이프라인 구축

초당 수만 건의 피크 동시 요청(TPS)에 대응 가능한 분산 이벤트 드리븐 아키텍처를 설계하고, 시스템 장애 격리(Bulkhead, Circuit Breaker) 메커니즘을 적용합니다.

3

지연시간(Latency) 최소화를 위한 고성능 캐싱(Redis) 및 분산 큐(Kafka) 최적화

Hot Data 메모리 인덱싱, Redis Cluster 토폴로지 튜닝, Kafka Partition 전략 수립을 통해 P99 레이턴시를 30ms 이하로 단축시킵니다.
